Excalidraw Tailscale Launcher

Runs Excalidraw, the room server, storage, reverse proxy, and Tailscale in Docker. Collaborators must be in your tailnet.

Use the local link on this computer. Send the Tailscale link to other devices only after they install Tailscale and sign in to the same tailnet. If the Tailscale admin console shows only one machine, no other device can open the private link yet.

Get this from tailscale.com. Sign in, open the admin console, go to Settings -> Keys, then click Generate auth key.

In the Generate auth key dialog, use a short description like Excalidraw Docker. Leave Reusable on if you want to restart this launcher without making a new key. Set the expiration to the number of days you want. Ephemeral can stay off because this launcher already has a Stop button and keeps Tailscale state in Docker.
